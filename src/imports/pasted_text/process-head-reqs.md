Process Head → Definition Module (Requirements)
1. Selected Standard View

When a Standard is selected, the system should display only the items related to that standard.

Items to display:

Procedures

Policies

Guidelines

Templates

Checklists

Each of these should be shown in a structured/filtered way based on the selected standard.

2. Add Record Option

Provide an “Add Record” button for the Process Head.

This should allow adding records under:

Procedure

Policy

Guideline

Template

Checklist

Each record should include required fields, for example:

Title

Description

Department / Standard Mapping

Version

Uploaded Document

Status (Draft / Approved)

3. Templates – Document Download Options

For Templates, documents should be downloadable.

Provide two download formats:

DOC

PDF

Rules:

If the procedure is Approved

Allow download only in PDF format.

If DOC format is selected

Show an Editable Version

User can edit the document and then download it.

4. Checklist & Guidelines

These should:

Be linked to the selected standard

Allow view and download

Be added through the Add Record option

5. Suggested UI Layout

Example structure:

Process Head
