## What's New?

### 🎯 One Dashboard, All Phases
Instead of selecting a single phase at login, you now have access to all three phases in one unified dashboard:
- **Definition Phase** - Define requirements and standards
- **Implementation Phase** - Execute and manage tasks
- **Validation Phase** - Review and verify compliance

### 🔄 Seamless Phase Switching
Switch between phases with a single click - no page reloads, no data loss!

### 📊 Shared Data Across Phases
All your work is connected. Requirements flow into tasks, tasks connect to validations, and everything is tracked in one system.

## Getting Started

### Step 1: Login as Process Head
1. Complete the initial questionnaire (if first time)
2. View the configuration summary
3. Click "Get Started" on the landing page
4. Select **Process Head** role
5. Enter your credentials and login

### Step 2: Select Any Process Phase
You'll be presented with three phase options:
- **Process Definition**
- **Process Implementation**
- **Process Validation**

Choose any phase - you can switch between them freely later!

### Step 3: Explore the Dashboard
Once logged in, you'll see:
- **Header** - Your profile and logout options
- **Phase Selector** - Three colorful cards to switch phases
- **Sidebar Menu** - Phase-specific navigation
- **Main Dashboard** - Overview and quick actions

## Common Tasks

### 1. Adding a Compliance Requirement

1. Click **Definition Phase** card
2. Click **Compliance Requirements** in sidebar
3. Click **Add Requirement** button
4. Fill in the form:
   - Standard name (e.g., "ISO 27001")
   - Clause number (e.g., "A.8.1.1")
   - Title and description
   - Priority, owner, due date
5. Click **Add Requirement**
6. Done! ✅

### 2. Creating and Assigning Tasks

1. Click **Implementation Phase** card
2. Click **Task Management** in sidebar
3. Click **Add Task** button
4. Fill in task details:
   - Task title and description
   - Assign to team member
   - Set priority and due date
   - Link to project
5. Click **Add Task**
6. Task is now visible to assigned team member! ✅

### 3. Conducting Quality Verification

1. Click **Validation Phase** card
2. Click **Quality Verification** in sidebar
3. Click **Add Quality Verification** button
4. Enter verification details:
   - Project name
   - Standard being verified
   - Checklist items reviewed
   - Verification result
5. Add observations
6. Click **Add Verification**
7. Verification complete! ✅

### 4. Generating Final Report

1. Click **Validation Phase** card
2. Click **Final Report** in sidebar
3. Click **Generate Final Report** button
4. Fill in report sections:
   - Project overview
   - Objectives and milestones
   - Task and issue summaries
   - Quality verification results
   - Performance metrics
5. Click **Generate Report**
6. Download PDF when ready! ✅

## Troubleshooting

### Issue: Can't See My Data
**Solution:** Make sure you're in the correct phase. Use the phase selector to switch.

### Issue: Menu Items Not Showing
**Solution:** Click the phase selector card to activate the phase first.

### Issue: Dialog Won't Open
**Solution:** Close any other open dialogs first, then try again.

### Issue: Search Not Working
**Solution:** Clear the search field and try again with different keywords.
